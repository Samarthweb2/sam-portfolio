# Samarth — Portfolio

A chalkboard-themed personal portfolio showcasing projects, highlights, and academic background.

> Note: This portfolio is currently under active development and being regularly updated.

## Sections

- **About**: Profile introduction, status note, and GitHub activity.
- **Lately**: Recent highlights, achievements, and milestones.
- **Education**: Academic background at ITM, Gwalior (Computer Science & Engineering).
- **Projects**: Selected development and engineering projects.
- **Connect**: Direct contact and social links.

## Tech Stack

- Frontend: Semantic HTML5, Vanilla CSS, JavaScript
- Backend / Serving: Python (Flask) / Node.js
- Assets: Custom SVG filters, chalkboard textures, and responsive layouts

## Running Locally

Clone the repository and run the local server:

```bash
# Option 1: Python (Flask)
pip install -r requirements.txt
python app.py

# Option 2: Node.js
node server.js
```

The application runs on `http://localhost:5000`.
